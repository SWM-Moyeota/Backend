## 📌 관련 이슈

비교 대안: #116(DB), #117(Redis). 세 PR은 같은 `develop`에서 출발한 **대체안**으로, 그대로 함께 병합하지 않습니다.

## 🔍 작업 내용

### 문제

동일 사용자가 서로 다른 방에 동시에 참가하면 방 행 잠금끼리는 충돌하지 않아 중복 활성 참여가 발생합니다. 앞선 PR에서 문서로만 검토했던 ZooKeeper 방식을 실제 서비스 입장 경계에 적용하고, 3노드 장애 실험까지 확장했습니다.

### 분석

Curator `InterProcessMutex`의 임시 순차 노드와 세션 기반 소유권은 DB 트랜잭션 수명과 다릅니다. 세션이 만료되어도 Java 코드·외부 DB 쓰기는 자동으로 멈추지 않습니다. 연결 복구를 기존 작업의 소유권 복구로 취급하지 않고, DB 현재 참여 PK와 방 행 잠금을 최종 방어로 유지합니다.

## 📝 변경 사항

### 실행

- Curator 5.9.0 사용자별 잠금을 DB 트랜잭션 시작 전에 획득하고 커밋/롤백 이후 해제합니다.
- SUSPENDED/LOST/READ_ONLY 관측 시 로컬 세대를 변경합니다. 획득 후·트랜잭션 진입·커밋 직전 같은 세대와 연결 상태를 검사합니다.
- 획득 실패·연결 장애는 DB로 우회하지 않으며 인터럽트를 보존합니다. 해제 실패는 이미 확정된 결과를 덮지 않습니다.
- 활성 참여 테이블과 V7 backfill, 방 저장 시 참여 동기화, 외부 경로 조회를 잠금 밖으로 이동하는 공통 변경을 포함합니다.
- 실제 PostgreSQL 공통 경쟁 시나리오와 테스트용 ZooKeeper 3노드 앙상블을 구성했습니다.

### 결과 및 검증

`MATCHING_BENCHMARK=true ./gradlew test`: **전체 460개 성공, 실패·오류·건너뜀 0개**.

작업자 16개·시나리오당 96건·3회 측정의 중앙값입니다. 완료 요청/초에는 정상 거절이 포함됩니다.

| 시나리오 | p50(ms) | p95(ms) | 완료 요청/초 | 관측 최대 DB 연결 |
| --- | ---: | ---: | ---: | ---: |
| 동일사용자 | 262.81 | 285.04 | 62.0 | 1 |
| 한방집중 | 91.08 | 99.16 | 175.4 | 16 |
| 분산참가 | 101.69 | 127.29 | 154.9 | 16 |

앞선 DB/Redis 측정과 실행 시점·서버 배치가 달라 운영 성능 순위로 일반화하지 않습니다.

장애 시험은 독립 세션 상호 배제, 연결 서버 1개 중단 후 과반으로 재개, 서버 2개 중단 후 SUSPENDED/LOST 관측 및 진입 거절, 복구 후 새 세대 획득, 만료 후 옛 소유자 해제가 새 잠금을 삭제하지 않음, 저장 후 만료 감지 시 DB 롤백을 포함합니다.

세션 만료 주입은 `getTestable().injectSessionExpiration()`을 사용했습니다. 실제 서버 중단 시험과 구분하며, 여러 호스트의 네트워크 분할을 검증했다고 주장하지 않습니다. 3개 서버는 독립 포트·데이터 디렉터리를 사용하되 **같은 테스트 JVM에서 실행**됩니다.

### PAAR에서의 선택 근거

문제 재현 → 잠금 수명과 DB 불변식 분석 → 같은 참가 시나리오 및 장애 실험 → 운영 비용까지 고려한 선택으로 설명합니다. 운영 장애를 해결한 경험으로 과장하지 않습니다. 현 MVP는 단일 PostgreSQL의 참가 정합성이 목적이므로 DB 방식을 우선 추천하며, 기존 ZooKeeper 인프라나 다른 조정 요구가 있을 때 도입을 재평가합니다.

## 💬 리뷰어에게

- 로컬 세대 검사와 `beforeCommit`은 fencing이 아닙니다. 감지 지연과 검사 후 커밋 사이의 경합이 남으며, DB PK가 활성 중복 참여를 최종 방어합니다. 오래된 요청의 최신성·HTTP 멱등 응답 저장은 별도 과제입니다.
- V7과 공통 클래스가 #116/#117과 겹칩니다. 다른 기능이 V7을 먼저 적용하면 미적용 번호 조정이 필요합니다. 기존 활성 중복 데이터와 구버전 노드의 혼재를 배포 전에 확인해야 합니다.
- 앱에는 별도의 ZooKeeper 앙상블 주소 설정이 필요합니다. 현재 구성은 신뢰된 로컬/사설 실험용이며 운영 ACL·인증·TLS는 제공하지 않습니다.
