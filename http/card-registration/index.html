카드 등록

카드 정보는 다음 단계에서 열리는 포트원·PG 창에 입력합니다. 등록 후 카드명과 끝 4자리를 확인할 수 있어요.

테스트 계정 로그인 API Secret이나 웹훅 시크릿을 입력하는 곳이 아닙니다. 로그인 토큰은 브라우저 저장소에 저장하지 않습니다.

로그인 사용자를 먼저 확인해주세요.

회원 정보에 저장된 이름·전화번호·이메일을 카드 등록 시 포트원·PG에 전달합니다.

이미 등록한 카드가 있으면 새 카드로 교체됩니다. 채널의 테스트/실연동 설정을 확인해주세요.

로그인 확인 → 카드 입력 → 우리 서비스에 저장
